# Velum Code 0.7.12

### GitHub Hub & Git Workstation
- **Live GitHub Hub**: Seamless repository integration connecting to the GitHub API via the GitHub CLI keyring (`gh auth token`) or stored Personal Access Tokens with non-blocking async IPC.
- **Issue & PR Integration**: Browse repository pull requests and issues, inspect branches, review labels, create issues, and pass truncated descriptions directly into agent prompts with **Ask Agent**.
- **Kanban Bridge**: Send any pull request or issue directly to your Kanban Backlog with one-click **Add to Kanban**.
- **Windows Verbatim Paths**: Normalized Windows `\\?\` path prefixes in `untracked_diff` so newly added files generate clean synthetic unified diffs in production.
- **Branch & Diff Resilience**: Support unborn repositories, detached `HEAD` states, and extended branch naming syntax (`@`, `+`, `~`, `^`, `{`, `}`).
- **Accessibility & Themes**: Fully compliant WAI-ARIA links, banner dismiss labels, container queries for embedded dashboards, and native token integration across dark and light atmospheres.

### Split Studio & Session Dashboard
- **Stable Tab Targeting**: Replaced intrusive automatic diff selection with explicit tab routing (`requestedTab`), preventing tab hijacking during turn transitions.
- **Telemetry & Tools Log**: View tool invocation reasons, token counts, and turn telemetry in the Tools Log with collapsible details.
- **Diff Inspection**: Surface 24 KB diff truncation notices, auto-clear stale file selections, and normalize Windows directory separators in touched file paths.
- **Draft & Tab Isolation**: Confined `velum:insert-draft` events strictly to the active session tab, avoiding unintended cross-tab draft injection, and reset changed file badges when repositories are clean.

### Interactions & Recovery UX
- **Turn-Scoped Approvals**: Promoted turn-scoped permissions (e.g. Codex `item/permissions/requestApproval` with `scope: "turn"`) to primary action bar status when one-time approvals are absent.
- **Keyboard Shortcuts**: Added `Ctrl+Enter` and `Cmd+Enter` keyboard submission to Interaction questions, free-text responses, Request Recovery, and Correction Composer.
- **Recovery Polish**: Added live character counters when approaching or exceeding message limits, and reset submitted state when a queued retry is dequeued.
- **Attention Indicators**: Added pulsing amber awaiting-response badges on background tabs and the Bots panel sidebar button.

### Bots, Energy Orb & Kanban
- **Energy Orb Physics**: Fixed double-energy multiplier and phase teleportation in `BotEnergyOrb.tsx`; implemented continuous `dt * speed` delta integration, idle frame rate throttling (~20fps), precomputed palette caching, and circular boundary clipping.
- **Bot Safety & Deep Linking**: Deep-link notification clicks directly to matching bot activity logs via `initialRunSessionId`; gracefully fall back to provider assistants when a referenced bot profile is deleted without bricking the session tab.
- **Security Invariant**: Enforced recipient bot `automatic` approval policy during bot-to-bot `Handoff` and `Delegate` actions to prevent unattended scheduling escalation.
- **Live Kanban**: Wired real-time board updates via `"kanban-changed"` events, added accessible Move Down (`↓`) keyboard buttons, and implemented 3-attempt revision race retries when background jobs finish.
